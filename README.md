
# Laravel Authentication Lab

## Project Overview
An IT Student Portal built with Laravel 12 for a university Web Development assignment.

## Features
- User registration
- Input validation
- Secure password hashing
- User login and logout
- Protected student dashboard
- Session-based authentication

## Requirements
- PHP 8.2 or newer
- Composer
- MySQL
- Laravel 12

## Setup
1. Install the project dependencies using `composer install`.
2. Create a MySQL database named `it_auth_lab`.
3. Configure your database credentials in the `.env` file.
4. Run `php artisan config:clear`.
5. Run `php artisan migrate`.
6. Start the application using `php artisan serve`.
7. Open http://127.0.0.1:8000.
